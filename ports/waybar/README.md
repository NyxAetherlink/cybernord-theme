# CyberNord for Waybar

This port styles Waybar without changing its module layout or behavior.

Install it as the active stylesheet:

```bash
cp style.css ~/.config/waybar/style.css
systemctl --user restart waybar.service
```

The font stack prefers IosevkaTerm Nerd Font, then JetBrainsMono Nerd Font,
with Font Awesome as an icon fallback.
